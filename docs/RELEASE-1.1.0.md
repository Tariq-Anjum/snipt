## Snipt 1.1.0

First public release. Android (arm64, Android 10+) and Linux (x86_64).

**Install**
- Android: download `Snipt-arm64.apk` below on your phone and open it, then tap *Set as default* in Snipt.
- Linux: `curl -fsSL https://raw.githubusercontent.com/Tariq-Anjum/snipt/main/install.sh | bash`

**Highlights**
- Self-sorting inbox (Personal, Priority, Transactions, Promotions, Spam) with Indian DLT sender parsing and offline translation.
- Encrypted OTP vault with 30-second clipboard wipe and screenshot blocking.
- UPI / credit card / savings ledger that ignores card limits, bill reminders, payment receipts and own-account transfers, and counts duplicate alerts once.
- Monthly budget planner with reset day, Start fresh and default limits.
- Home-screen widgets (messages, monthly budget), Settings, System/Light/Dark theme with Pure black, pinch-to-resize text.
- Encrypted backups to any cloud app via the system file picker.
- No internet permission.

**Checksums:** `SHA256SUMS` (also verified automatically by `install.sh`).
